# 发布说明（Release Notes）

> 每次发布把对应段落原样粘贴到 GitHub Release 正文。
> 版本号唯一事实来源是 `app/build.gradle.kts` 的 `versionName` / `versionCode`。
> 当前两个版本均标记为 **Pre-release**（GitHub 上勾选 *Set as a pre-release*）。

| 版本 | versionCode | 日期 | 类型 |
| --- | --- | --- | --- |
| v1.2.0 | 30 | 2026-11-10 | Pre-release |
| v1.1.0 | 29 | 2026-11-10 | Pre-release |
| v1.0.0 | 26 | 2026-11-09 | Pre-release |

> 附件命名与 tag 一致：`Kavita-v1.2.0.apk` / `Kavita-v1.1.0.apk` / `Kavita-v1.0.0.apk`。
> `:app:packageDebugApk` 直接输出这个文件名（不带 `-debug`）。包名自 v1.2.0 起为 `com.kavita.reader`
> （v1.0.0–v1.1.0 误写为 `com.kativa.reader`）—— 因此 **v1.2.0 无法覆盖升级旧版**，升级前请先卸载。
> 下面各段正文可直接粘贴，不含构建类型信息。

## v1.2.0

**建议 Release 标题**：`v1.2.0 (Pre-release)`

```markdown
## Kavita for Android v1.2.0 · Pre-release

> Kavita 自建阅读服务器的第三方 Android 原生客户端（非官方）。
> versionCode 30 · Android 8.0+ (minSdk 26)
> 本版本为预发布版本，欢迎试用并反馈问题。

本版是**纯命名修正版**：项目名此前误写为 Kativa，现统一纠正为 **Kavita**。

### 变更

- **应用包名**：`com.kativa.reader` → `com.kavita.reader`。
- **应用内标识**：所有 `Kativa*` 类名与设计系统组件（主题、图标、顶栏、滑块、开关、输入框、进度条、导航）统一改为 `Kavita*`；主题名 `Theme.Kavita`。
- **深链**：`kativa://...` → `kavita://...`。
- **网络标识**：`User-Agent: Kavita/<version> (Android <api>; Mobile)`，请求头 `X-Kavita-Client: kavita-android`。
- **本地存储键**：DataStore 文件与 Room 数据库统一为 `kavita_*` 前缀。
- **仓库地址**：<https://github.com/page7/kavita_android>。
- 功能与 UI 与 v1.1.0 完全一致，无行为变更。

### 升级注意（包名变更，必须卸载）

- 包名变了，系统会把新旧两版视为两个独立应用，**无法覆盖安装**。
- 请先卸载旧的 `com.kativa.reader`（或 `com.kativa.reader.debug`），再安装本版，然后重新添加服务器并登录。
- 本 App 不缓存书库内容，卸载不会丢失阅读进度（进度保存在你的 Kavita 服务器上）。

### 质量

- 单元测试 **283 个用例全绿**（改名后全量重跑）。
- 冷启动冒烟通过：`pidof com.kavita.reader` 非空、logcat 无 `FATAL EXCEPTION`、首屏服务器表单正常渲染、带异常参数的 `kavita://setup` 深链不崩。
```

## v1.1.0

**建议 Release 标题**：`v1.1.0 (Pre-release)`

```markdown
## Kavita for Android v1.1.0 · Pre-release

> Kavita 自建阅读服务器的第三方 Android 原生客户端（非官方）。
> versionCode 29 · Android 8.0+ (minSdk 26)
> 本版本为预发布版本，欢迎试用并反馈问题。

本版聚焦**阅读器的记忆与手感**：阅读设置不再是一次性的，横屏与缩放都真正好用。

### 新增

- **阅读设置按系列持久化（三级回落）**：阅读方向 / 翻页模式 / 页面布局 / 图片适配 / 封面单独 / 显示页码 现在按「系列 → 全局默认 → App 默认」逐级回落，退出阅读器或切章节后不再被重置。关闭/删除服务器时，会一并清理该服务器名下的阅读设置。
- **设置页新增「阅读 → 默认阅读设置」**：复用阅读器里同一个设置抽屉（隐藏亮度与「恢复本系列」），避免两套 UI 各自漂移。
- **阅读器新增「横屏显示」**：进入阅读时强制横屏（系统关闭自动旋转也生效），退出自动恢复原方向，旋转不重建 Activity。
- **阅读器新增「恢复本系列的阅读设置」**：清掉本系列的覆盖值，回落到你在设置页配置的**全局默认**（不是出厂默认）。
- **双击放大**：双击以双击点为中心放大到 2.5×，放大后单指拖动、双指捏合（1×–5×），捏回原始比例自动退出；翻页 / 切换模式 / 切换布局会同步复位缩放。放大期间由页面接管手势，`Pager` / Webtoon 不再抢同一个拖动，翻页与三分区点击在未放大时行为不变。

### 修复与优化

- **阅读器底部栏过高**：页码不再与上一章/下一章按钮同排（不再继承 48dp 触摸高度），进度滑块去掉拖动浮泡，底部栏高度显著下降，不再压住画面。拖动滑块时页码行实时显示目标页，拖动期间只更新本地状态，松手才真正跳页 —— 不再抖页、不再反复重写进度。
- **书签手势收敛**：双击改为放大，书签统一走顶栏按钮（空态文案同步更新）。
- 四语言（中 / 英 / 法 / 日）文案同步，共 253 条对齐。

### 已知限制

- EPUB / PDF 阅读器仍在开发中，遇到该格式会明确提示，不会假装渲染。
- 本版本为预发布（Pre-release）版本，功能与接口仍可能调整，请勿用于关键数据场景。

### 升级注意（包名变更）

- 从本版本起 debug 构建不再使用 `.debug` 后缀，包名为 `com.kativa.reader`（v1.2.0 起已更正为 `com.kavita.reader`）。
- 旧包与旧数据不会自动迁移：请先卸载旧的 `.debug` 版本再安装本版，然后重新添加服务器并登录。

### 质量

- 单元测试 **283 个用例全绿**（新增阅读设置持久化、双击缩放、底部栏布局守卫）。
- 关键修复均做了反向验证：把实现改回旧逻辑，对应测试会立即失败。
- 真机 / 模拟器验证：4 页连续「放大→退出→翻页→再放大」全部成功，Webtoon 模式同样通过；改横屏进入/退出方向正确；冷启动无 `FATAL EXCEPTION`。
```

## v1.0.0

**建议 Release 标题**：`v1.0.0 (Pre-release)`

```markdown
## Kavita for Android v1.0.0 · Pre-release

> Kavita 自建阅读服务器的第三方 Android 原生客户端（非官方）。
> versionCode 26 · Android 8.0+ (minSdk 26)
> 本版本为预发布版本，欢迎试用并反馈问题。

第一个正式版本：**打开 App 3 秒内能接着上次的进度继续读**。多服务器、隐私模式、漫画阅读器、进度同步与四语言均已落地。

### 阅读

- **漫画阅读器**：单页 / 双页 / 双页漫画 / 上下翻页 / Webtoon 连续滚动五种呈现；分区点击翻页、页码跳转、章节切换（章末「下一章」过渡，不自动跳）。
- **阅读设置抽屉**：方向（LTR/RTL）、翻页模式、页面布局、图片适配、封面单独、亮度（暗色遮罩，仅本次阅读）、显示页码、音量键翻页；只暴露真正生效的选项。
- **进度同步**：翻页 800ms 防抖 + `ON_PAUSE`/`ON_STOP` 立即提交，写后队列落 Room，断网补传，跨设备续读；读完按服务端规则保存为 `maxPages + 1`。
- **编号显示修复**：`-100000` / `100000` 等哨兵值不再外泄，散章与番外单独成区块，显示为「全一章 / 单话」。

### 浏览与检索

- **多服务器**：可保存多台 Kavita 服务器，启动默认进服务器选择页（不自动登录），可指定「启动时自动登录的服务器」；会话、Token、图片缓存、隐私开关全部按服务器隔离。
- **登录**：账号密码 + API Key 两种方式，支持粘贴含 apiKey 的 OPDS/登录链接自动提取并预填。
- **首页**：On Deck / 最近更新 / 新入库流 + 资料库文件夹（含真实系列总数与四宫格拼图），搜索与用户中心入口。
- **书架**：库 → 系列自适应网格，触底加载、排序（名称 / 加入时间 / 阅读时间，升降序）与筛选（名称搜索 + 仅收藏），旧请求回包不会覆盖新结果。
- **系列详情**：卷折叠、章节列表、整体进度、标记已读/未读，「想读」加入/移出（乐观更新 + 失败回滚）。
- **搜索**：300ms 防抖、1 字符即可命中、按系列/合集/阅读清单分组、会话内历史。
- **合集 / 阅读清单 / 想读**：统一书架页面（三种 kind），阅读清单按清单顺序续读。
- **我的书签**：入口在「我的」页，缩略图网格 + 直达书签页。

### 隐私与外观

- **隐私模式**：主界面一键开关，开启后**封面根本不发起请求**（不是加载后打码），直接渲染纯色占位图；按服务器持久化，一到四级页面全部生效（Coil 层还有兜底拦截，阅读器正文不受影响）。
- **主题**：主色 `#4AC694` / 深色主题 `#2D7A56`，暗色优先、支持跟随系统；关闭 M3 动态取色以保护封面视觉。
- **多语言**：中文 / English / Français / 日本語 四套同步。

### 已知限制

- EPUB / PDF 阅读器、阅读配置（Reading Profiles）服务端写回、阅读统计等仍在后续版本。
- 不做下载与离线阅读：阅读需联网，进度离线入队、联网补传。
- 本版本为预发布（Pre-release）版本，功能与接口仍可能调整，请勿用于关键数据场景。

### 质量

- 单元测试 **243 个用例通过**，覆盖 Mapper、分页、URL 构造、进度换算、隐私拦截、序列化线上负载等。
- 冷启动冒烟通过：进程存活、首屏渲染、无 `FATAL EXCEPTION`。
```
