> 配套文档：`../AGENTS.md`（工程契约）、`FLOWS.md`（使用流程）、`PAGES.md`（页面设计）、`FEATURES.md`（功能规划）、`API.md`（接口清单）、`ASSETS.md`（素材清单）。

## 1. 一句话定位

**Kavita 服务器的 Android 原生阅读端**：把"自建书库"变成"口袋里随时能翻的书"，核心是**多服务器、续读、翻页体验**，而不是把 Web 管理后台塞进手机。

### 1.1 我们做 / 不做

| 做 | 不做 |
| --- | --- |
| 多服务器管理与登录、继续阅读、浏览、搜索、筛选 | 建库、扫描、用户管理、系统设置 |
| 漫画/图片/EPUB/PDF 阅读器与阅读配置 | Kavita+ 订阅购买、License 管理 |
| 进度同步、书签、合集、阅读清单、想读 | 服务端元数据编辑（v1 只读） |
| 隐私模式（封面屏蔽）、四语言（中/英/法/日） | **章节/系列下载与离线阅读**（明确不做） |
| SVG→PNG 素材管线与占位替换 | OPDS 服务端实现 |

### 1.2 目标用户与场景

1. **多服务器用户**：家里一台 Kavita、公司一台/朋友一台 → 启动选服务器，或设置默认自动登录。
2. **多设备用户**：家里平板读到 37 页，手机打开继续第 37 页。
3. **追更用户**：首页"最近更新"看新章节，一键续读。
4. **公共场合读者**：开启隐私模式，列表里只剩深灰占位图与文字。
5. **收藏型用户**：维护"想读"与阅读清单，按清单顺序推进。

### 1.3 设计原则

- **启动先选服务器**：默认不自动登录；自动登录是可选偏好，指向某一台服务器。
- **续读优先**：进入服务器后首页第一屏永远是"继续阅读"，任何路径 2 步内能回到上次那页。
- **封面驱动**：暗色底 + 2:3 封面网格，封面即导航；隐私模式下一律占位图。
- **一屏一任务**：每页只有一个主行动（继续读 / 开始读）。
- **失败可恢复**：任何错误都有出口（重试/换服务器）。
- **服务端为真相**：本地只做缓存与队列，冲突时明确规则（见 AGENTS §7）。

## 2. 信息架构

```
Kativa
├─ 启动
│  ├─ Splash（读会话 → StartupRouter）
│  ├─ Welcome（仅 logo；无服务器时出现）
│  ├─ ServerSelect（服务器选择页，默认入口；含"添加服务器"）
│  │    ├─ 设置了"启动自动登录"且会话有效 → 跳过选择页直达该服务器首页
│  │    └─ 未设置/会话失效 → 停留在选择页
│  ├─ ServerSetup（地址、明文开关、证书信任、启动自动登录开关）
│  └─ Login（账号密码 / API Key）
├─ 主导航（底部 4 项）
│  ├─ 首页 Home          → 继续阅读 | On Deck | 最近更新 | 新入库 | 智能筛选流
│  ├─ 书架 Library        → 库列表 | 库内系列（网格/列表、排序筛选、跳字）
│  ├─ 发现 Discover       → 搜索 | 合集 | 阅读清单 | 浏览（类型/标签/作者）| 想读
│  └─ 我的 Me             → 个人资料 | 阅读统计 | 阅读配置 | 设置 | 关于
├─ 详情
│  ├─ 系列详情 Series     → 卷/章、元数据、相关作品、评分评论
│  ├─ 卷详情 Volume
│  └─ 章节详情 Chapter
├─ 阅读器 Reader
│  ├─ 漫画阅读器 Manga    → 单页/双页/Webtoon
│  ├─ EPUB 阅读器 Book
│  └─ PDF 阅读器 Pdf
└─ 次级页面
   ├─ 搜索 Search
   ├─ 合集详情 / 阅读清单详情
   ├─ 书签 Bookmarks
   ├─ 阅读配置 ReadingProfiles
   ├─ 设置 Settings（服务器/账户/阅读/外观/语言/网络/关于）
   └─ 关于/致谢/开源许可
```

**顶部全局控件**（首页与书架等主界面右上角）：搜索图标、**隐私模式开关**（眼睛/遮罩图标，激活态高亮）。无通知中心、无通知点。

### 2.1 底部导航决策

| 项 | 图标语义 | 为什么在底部 |
| --- | --- | --- |
| 首页 | Home | 高频、续读入口 |
| 书架 | Grid | 按库浏览是主路径 |
| 发现 | Compass | 搜索/合集/清单/想读聚合，避免更多 tab |
| 我的 | Person | 低频但需可达（服务器、设置从这里进） |

- 只有 4 项（**下载已移除**）；**设置不占 tab**（从"我的"进入）。
- 平板（≥ 840dp）：底部导航 → `NavigationRail`（左侧），列表与详情并排（列表 40% / 详情 60%）。
- 阅读器为 **全屏独立目的地**，不显示任何导航栏（隐私模式开关在阅读器内不出现，正文页不受隐私模式影响）。

### 2.2 导航层级与返回行为

- 深链：`kativa://series/{id}`、`kativa://reader/{chapterId}`、`kativa://library/{id}`、`kativa://list/{id}`、`kativa://collection/{id}`。
- 深链进入时若无当前服务器上下文 → 先落到服务器选择页。
- 从"继续阅读"进入阅读器，返回键先回系列详情（不是首页），再次返回回首页。
- 底部 tab 切换保留各自返回栈（`saveState/restoreState`），重复点击当前 tab = 回到该 tab 根 + 滚动到顶。
- 在"我的 → 切换服务器"可随时回到服务器选择页（不清除其它服务器会话）。

## 3. 技术布局

### 3.1 模块化（单 module 起步，保留拆分点）

```
:app                  组装、导航、DI、Application
:core:designsystem    Theme/Tokens/通用组件
:core:assets          素材注册表（SVG→PNG 占位与正式素材，见 docs/ASSETS.md）
:core:network         Retrofit/OkHttp/鉴权/分页/错误映射
:core:data            Repository、Room、DataStore、进度同步
:core:model           domain model + 枚举
:feature:servers      服务器选择 / 添加 / 设置（含启动自动登录）
:feature:auth         login
:feature:home         home streams
:feature:library      library / series / volume / chapter
:feature:discover     search / collections / lists / browse / want-to-read
:feature:reader       manga / epub / pdf / settings sheet
:feature:me           profile / stats / settings
```

> 初期用单 `:app` + 分包（`core/ data/ domain/ ui/`）即可，**M3 前不拆 Gradle module**，避免过度工程；上表是拆分蓝图，包边界必须按此保持，拆分时零改动。

### 3.2 状态与数据流

```
Compose Screen ──(event)──▶ ViewModel ──▶ UseCase ──▶ Repository ──▶ Retrofit / Room / Files
      ▲                         │
      └────── UiState ◀─────────┘  (StateFlow + immutable data class)
```

- 列表页统一 `UiState`：`Initial | Loading | Content(items, endReached) | Empty | Error(KativaError)`。
- 阅读器独立状态机（`ReaderUiState`）：`Preparing → Ready(page,maxPages) → Saving → Finished`。
- 跨页面共享：当前服务器（`ActiveServerStore.current: StateFlow<ServerProfile?>`）、登录用户（按 serverId 的 `SessionStore`）、隐私模式开关、主题、语言。

### 3.3 缓存与同步策略（无离线下载）

| 数据 | 位置 | 失效 |
| --- | --- | --- |
| 服务器档案（多台） | Room `server_profile` | 用户删除 |
| token/refreshToken/imageKey | DataStore（Keystore 加密，按 serverId 分键） | 登出/刷新/删服务器 |
| 用户与偏好 | 内存 + DataStore 快照 | 启动刷新 |
| 库/系列/章节列表 | Room（轻投影，含 serverId）+ 内存分页缓存 | 下拉刷新 / TTL 10 分钟 |
| 封面 | Coil 磁盘缓存（512MB，按 serverId 目录） | 隐私模式不请求；手动清理 |
| 阅读页（漫画/PDF/EPUB 页） | Coil 缓存 / app cache（PDF 临时文件） | 会话结束按 LRU |
| 进度 | Room 待同步队列 + 服务端 | 同步成功删除 |
| 搜索历史、隐私模式开关、自动登录选择 | DataStore | 用户清除/切换 |

### 3.4 关键非功能指标

| 指标 | 目标 |
| --- | --- |
| 冷启动到首页首屏 | < 2s（有缓存） |
| 首页"继续阅读"可点 | < 1s |
| 阅读器打开章节首图 | < 1.5s（局域网） |
| 翻页掉帧 | 0（P95 帧时 < 16ms） |
| 进度丢失率 | 0（退出必落盘） |
| APK 体积 | < 25MB |
| 崩溃率 | < 0.2% 会话 |

## 4. 视觉方向

- **主题色**：主色 `#4AC694`，深色主题色 `#2D7A56`。浅色主题用主色，深色主题用深主题色（按钮/激活态/进度环同色系）。
- **暗色为主**：`#0B0B0F` 背景 / `#15151C` 卡片 / 进度色 `#4AC694` / 警告 `#F59E0B`。
- 首页顶部为"继续阅读"大卡：左侧封面（带进度环），右侧系列名 + 章节名 + "继续第 N 页"按钮。
- 所有封面 2:3、圆角 12dp、底部渐变压字；未读角标为品牌色小圆点，已读为 60% 透明度。
- **隐私模式占位图**：纯色 + 极淡 logo 水印（素材 `privacy_placeholder.png`），保持 2:3 比例与圆角，进度条/文字照常显示。底色跟随主题：暗色 `#3A3A3A`、亮色 `#E9EBEF`。
- 详情页允许用 `primaryColor/secondaryColor` 生成柔和渐变头图（无封面时降级为纯色）。
- 动效克制：共享元素（封面 → 详情头图）、阅读器翻页 200ms、无弹跳。
- 欢迎页：**只有 logo**（居中，深色底），无插画、无宣传语；停留 1.2s 后（或首次点击）进入服务器选择/添加流程。

## 6. 与 Web 端的差异（有意为之）

1. **不做管理后台**：管理员请用 Web。
2. **不做下载/离线**：阅读依赖网络；Web 端有下载入口，本 App 不提供。
3. **导航重构**：Web 的侧边栏 + 仪表盘 → 移动端底部 4 tab + 流式首页（可自定义排序的流在设置里管理）；**无通知点**。
4. **多服务器**：Web 是单服务器；本 App 服务器档案可增删，启动默认选择页。
5. **首页流**：保留 On Deck / 最近更新 / 新入库 / 智能筛选，但**默认只显示 3 个**，其余在"编辑首页"里开启。
6. **隐私模式**：Web 无对应功能，是本 App 独有的封面屏蔽开关。
7. **外链跳转**：Kavita+ 相关（评分/评论/推荐）只读展示并标注来源，不提供登录第三方。
8. **阅读配置**：移动端只暴露常用项（方向、布局、缩放、亮度、音量键），高级项折叠。
